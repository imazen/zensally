# Bounded people supervision pilot

Person boxes are auxiliary localization/relationship supervision. They do not
replace face protection or artistic composition targets, and do not require
every hero/detail crop to retain every whole body. The current18 people fitting
scenes are too narrow for the measured generalization failures.

Bind the two frozen MIAP metadata packets and existing canonical/historical,
photographic and supplementary role manifests. Before any new pixel or teacher
score, join exact provider photo IDs, original MD5s, source links and author
profiles into connected components. Quarantine a whole component on any alias
overlap with prior references; never move an existing role. Normalize Flickr
NSID aliases, preserve case-sensitive Unsplash IDs and exclude licence links/
human-name coincidences from identity keys. Keep every original hyperlink.

Assign new components once by a fixed seed31 hash:70% fitting,15% development,
15% TEST. These are metadata roles with training eligibility still false.
Select at most480 sources, one per component, by fixed hash order within twelve
box-count/scale cells. Each cell allows24 fit/eight development/eight TEST;
shortfalls stay explicit, never reroll a split. Count cells use1/2/3–5/6+ box
records, including group records, not a certified count of individual people.
Scale is maximum person-box normalized area:<0.02/<0.2/otherwise. These are
sampling proxies, not visual content judgments or model targets.

The first acquisition pool excludes missing source metadata, invalid annotation
geometry, prior overlaps, depictions and nonzero rotation. Zero-rotation metadata
does not establish pixel/annotation orientation: verify actual JPEG dimensions,
EXIF convention and overlay alignment before admission. Nonzero/missing rotations
remain retained for later convention checks; no general rotation claim follows.
Demographic annotations are unused. Existing corpora and guards stay unchanged.

Exact provider metadata is incomplete for some old sources. Original MD5 and
reference SHA256 are different identities and cannot be directly compared.
No matches must not become a claim of complete disjointness. After bounded
acquisition, compare owned decoded hashes/fingerprints with available frozen
references, quarantine conflicts and document coverage. No old holdout pixels
are opened merely to strengthen that comparison. Upstream pretraining exposure
is a separate unresolved limitation.

This stage budgets256MiB outputs and2GiB host/one thread, acquires no images,
admits no targets and calls no paid model. Pixel acquisition must retain original
bytes/headers/URLs, check per-source attribution, respect a declared bound, use
owned decoders/resizing and independent readback, and leave TEST pixels closed.
Artistic ranking and face-class supervision remain distinct follow-up work.

Before larger acquisition, use the first frozen fitting source in each of the
twelve cells as a witness set. Retain CVDF JPEG bytes, source attribution and
HTTP headers; bound each download to8MiB and the full stage to128MiB. This is a
CVDF derivative, so its content hash must not be equated with OriginalMD5.
Require RGB JPEG, orientation1, at most32MP and agreement of independent source
headers with owned preview dimensions. Use the pinned strict-sRGB/Lanczos3
preview tool at768 long edge without upscaling, owned PNG decoding and exact
independent PNG sample readback. Overlay every person box for bounded review.
The first witness stage is fitting-only, under2GiB/one thread, and still admits
no training, complete-face or artistic label. Preserve failed partials/caches.

The completed witnesses expose a magazine cover, a statue target with depiction
flag0 and a two-record crowd. A separate group-aware sampling plan inherits every
frozen source/component role and the original within-cell hash order. It changes

Keep the original pilot and all witness bytes intact. Separate1/2/3–5/6+ individual
records from group+individual scenes; use maximum individual-box area for scale,
never the group rectangle. Group-only sources have unresolved individual scale.
This gives16 cells, at most18 fit/six development/six TEST per cell, one source
per component and480 total; report shortfalls rather than rerolling a split.
All sources still require content/target review before fitting. This is a data
sampling correction, not a claim of complete human counts, faces or better crops.
