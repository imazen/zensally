# Photographic subject-retention suitability

Keep the existing94-fit/25-development/25-TEST provider registry and all frozen
rank/extent studies unchanged. Use only existing fit/development sources here;
the supplementary fifteen-family cohort remains outside gradients and selection
until a new fixed-model evaluation plan exists. No paid API calls.

First establish offline references for people, featured products, animals and
prepared food. Author one coarse subject phrase for each of the87 matching
sources in the frozen119-source content review:72 fit and15 development. Other
sources have unknown subject targets, not negative labels. Content observations
choose query scope only; they are not artistic grades or exhaustive annotations.
Queries intentionally describe coarse subjects, not brand text, fine details or
inferred identities. Multiple objects/people may be grouped into a query box.

Use the already pinned native Florence checkpoint and owned Lanczos stretch768
input path, FP16/eager/TF32-off, three deterministic beams and512 new tokens.
Bind source ID/family/role, working RGB, native geometry, authored phrase and
complete model contract into cached responses. Retain full tokens/text, parsed
entities, termination and errors. Empty, invalid or truncated outputs are unknown.
No reference is a complete-face certificate or a human artistic-quality label.
Preserve the prior query/cache contracts and never overwrite their evidence.

Before fitting, audit reference geometry and inspect bounded examples of people,
products, animals and pre-truncated source subjects. Record invalid/empty counts
by source role/category and retain counterexamples. Only valid fit-source boxes
may later supply weak retention supervision; development supplies diagnostics.
Teacher outputs do not automatically become trusted face bounds.

The first87-source visual audit finds that activity-specific people phrases can
select props: the seated-reader query selects a phone, and the counter-reader
query selects a book/counter. Preserve those failures. Before person-label
admission, repeat all20 people scenes (18 fit/two development) with the identical
generic phrase `The people.` rather than selectively correcting only failures.
Bind this follow-up as a separate source plan and cache; no original output is
overwritten. Compare both results visually, without calling either exhaustive.

The proposed next model predicts candidate-region retention from the same RGB,
source geometry and fixed crop candidates available at runtime. It will reuse
the existing photographic ranking encoder and region pooling, with separate
ranking/retention outputs. Offline grounded regions are targets, never a required
inference input. Measure actual known-region retention, errors on all three
seeds, geometry-only/permuted controls, and real geometric infeasibility versus
coarse candidate-bank misses. Register objective, epochs and model selection
before fitting. Catalogue whole-subject constraints and hero/detail composition
are distinct uses; this first study establishes retention suitability, not a
complete purpose-aware artistic crop model.

The original candidate bank, rank model, face-review gates and Minimal/Maximal
contracts remain frozen. No learned retention score certifies face safety.
Do not optimize another global one-box extent head merely to lower fitting loss.
