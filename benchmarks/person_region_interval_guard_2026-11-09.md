# Direct automatic person-region interval constraints

Direct constraints reduce nominated-head cuts much more than learned region
coordinates, but lost crop availability and remaining broader failures prevent
promotion. Across five parents, upper-body constraints offer95/139 accepted
DEV endpoints; full-body constraints offer86. These are44 and53 withdrawals,
not free safety gains. Original-quality compatibility is not established.

The [registered control](../docs/experiments/PERSON_REGION_INTERVAL_GUARD.md)
reuses existing Lite2 confidence0.3/max50 detections on72 sources. Padded
upper45-percent and full-person views enter the unchanged exact interval
solver. Minimal retains maximum native aspect extent. Inner is enlarged only
as needed, remains strict, and retains every proposed region in outer; other
people can be excluded completely. All proposals stay, except exact duplicates.
Two nondetection sources retain parents with explicit unchecked status.

Five frozen geometry/region parents replay all7920 endpoint audit rows exactly
before constraints. Ten controls evaluate7920 pairs, with no teacher/detector
inference, fitting, new labels, paid calls or TEST. Each emitted supplied-region
pair passes the continuous interval guard. This guarantees only those proposed
regions, not all real heads or artistic composition.

## Actual pixels and failure mechanism

All12 rendered panes were inspected, with owned resize/encoding and independent
exact PNG readback. Tourism source333164d55912bd3c at3:1: parent emphasizes
architecture, while constraints move to the people below. This clears a weak
cut flag but selects a different story; it is not an excellent-crop label.
Gymnast source7576a708d241c078 at4:3: the person is upside down. Protecting the
upper part of the box moves the crop upward and cuts the face. Full-body
constraint offers neither crop. The upper-view heuristic assumes body
orientation that this image violates. Existing cached face proposals locate
the upside-down face; cached pose-head proposals for this source are empty.
This suggests combining measured face/pose locations with body fallback rather
than treating box top as head position; that combination is not measured here.
