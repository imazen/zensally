# Nominated-head interval oracle

Incomplete automatic head proposals explain many remaining cuts, while better
geometry alone leaves composition matching low. This is a conditional diagnostic
using cached weak nominations, not a deployable detector or face certification.
No new labels, gradients, API spending, TEST access or model promotion.

The [registered control](../docs/experiments/NESTED_ORACLE_DIAGNOSTIC.md)
substitutes every valid cached nominated head for automatic face/pose proposals,
with zero extra padding, preserving the same three parent pairs and exact
refinement solver. All original cached positive masks replay unchanged. Invalid
annotations and no-head sources remain explicitly unchecked.
