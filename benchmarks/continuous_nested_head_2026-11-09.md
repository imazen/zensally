# Continuous nested-pair head suitability

This head fails suitability and is not exported. Continuous output removes the
fixed candidate-bank restriction and guarantees paired geometry, but all image
and attention controls have worse held-out paired error than geometry alone.
They still cut nominated heads. No API spending, TEST access or quality-gate
relaxation; no model is promoted.

## Data and architecture

The [registered experiment](../docs/experiments/CONTINUOUS_NESTED_HEAD.md)
reuses existing weak endpoint nominations.99 same-story safe pair requests
exist across29 FIT families;36 across14 DEV families. Essential counts are
97/36, with two additional FIT secondary requests. There is exactly one admitted
combination per eligible request in this cache. These are finite weak endpoint
targets, not excellent labels or accepted intermediate ranges. Original48 FIT/
24 DEV source roles remain fixed;19 FIT sources without a pair supply no crop
gradients. All48 FIT sources supply the frozen descriptor normalization.

One136677-parameter head predicts a single pair per aspect. The outer always
has maximum native exact-aspect extent; the tighter inner is parameterized
relative to it. No best-of-two selection or arbitrary slot ordering. Five
equal-capacity arms use geometry, frozen C002 source-grid descriptors, aligned/
permuted attention distillation, or actual measured attention inputs. Attention
summaries average the existing32 pose/gaze/scanpath values over eligible bank
candidates and modes; this experiment does not test every attention encoding.

Fifteen fits complete64 epochs plus zero with matched seeds31/137/911,
AdamW0.001/decay0.0001, clip5, eight source families/batch. DEV selection uses
source-balanced maximum endpoint edge error to the existing joint reference,
then earliest epoch. Unknown requests supply no coordinate gradient. Selected
metrics/native outputs replay exactly before separate CPU qualification.
